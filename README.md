# AminTech — Soluções Inteligentes com IA

Desenvolvendo aplicações Java inteligentes com IA para automatizar processos e transformar negócios.

## 🚀 Tecnologias Estudadas e Aplicadas

- **Java & Spring Boot** — Desenvolvimento de ecossistemas e APIs corporativas robustas.
- **Integração de IA via APIs** — Conexão de aplicações Java a modelos de linguagem (LLMs).
- **Sistemas de RAG** — Consulta inteligente a documentos e bases de conhecimento.
- **Agentes de IA & MCP** — Sistemas com ferramentas, memória e automação de processos.

## 🗺️ Roteiro futuro

Além dos módulos já estruturados acima, o plano de estudo inclui:

- **Tools / MCP (Model Context Protocol)** — padronização de como uma IA se conecta a ferramentas externas.
- **Automação de processos** — fluxos que executam ações de ponta a ponta sem intervenção manual.
- **Projeto final** — um sistema completo que integra todos os módulos anteriores.
